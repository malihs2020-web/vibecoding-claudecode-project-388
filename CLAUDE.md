# parcer

Набор Claude Code skill'ов для отслеживания и разового поиска цен на товары в интернет-магазинах через Telegram-бота.

## Не трогать

- `.github/workflows/hexlet-check.yml` — сгенерирован автоматически (это учебный проект Hexlet, отсюда и название репозитория `vibecoding-claudecode-project-388`), нельзя удалять/редактировать/переименовывать репозиторий.
- `.env`, `telegram_bot_state.json` — секреты и рантайм-состояние, не коммитятся (см. `.gitignore`), не читать напрямую без необходимости.

## Skills

| Skill | Что делает |
|---|---|
| `tracker` | Отслеживает цену одного зашитого товара (Premier, ягнёнок с индейкой, для собак средних пород, 10 кг) по фиксированному списку URL + маркетплейсам (Ozon/Яндекс Маркет/Wildberries, если доступен браузер). Сохраняет каждый прогон в приватный репозиторий `malihs2020-web/tracker-data`, сравнивает с предыдущим прогоном по правилам из `KNOWLEDGE.md`, шлёт сводку значимых изменений в Telegram через `send.py`. |
| `extract-price` | Извлекает цену с одной уже данной страницы товара по URL. Строительный блок для `tracker` и `telegram-price-bot` — сам источники не ищет. |
| `telegram-price-bot` | Слушает тот же Telegram-бот на произвольные товарные запросы (не только зашитый корм) и отвечает топ-5 самых дешёвых точных совпадений со ссылками. Разовый поиск, без истории. Работает только пока открыта сессия Claude Code (динамический `/loop`, запуск фразой «слушай телеграм», стоп — «хватит слушать»). |

## Архитектура

| Путь | Назначение |
|---|---|
| `receive.py` | Опрашивает Telegram (`getUpdates`) на новые сообщения для `telegram-price-bot`. |
| `send.py` | Отправляет сообщение в Telegram-бота; читает `TELEGRAM_BOT_TOKEN`/`TELEGRAM_CHAT_ID` из `.env`. |
| `KNOWLEDGE.md` | Правила значимости изменения цены (±2% и одновременно >50 ₽) — использует `tracker` для diff и сводки в Telegram. |
| `telegram_bot_state.json` | Рантайм-состояние опроса Telegram (`last_update_id`) для `telegram-price-bot`, не коммитится. |

## Ключевые паттерны

**Точное совпадение**: поиск по цене на маркетплейсах смешивает разные модификации товара (вес/вкус/размер) — всегда отфильтровывать по точному соответствию запрошенным характеристикам, не брать более дешёвый, но неподходящий вариант. Правило описано в `tracker/SKILL.md`, переиспользуется остальными skill'ами по ссылке, не копируется.

**Безопасная отправка в Telegram**: текст, отправляемый в `send.py`, может содержать кавычки/`$`/переносы строк — писать его во временный файл (инструмент Write) и подставлять через `$(cat "<путь>")`, не вставлять как буквальный текст в команду.
